    Use it in Claude

    1. Download the skill (.zip)
    2. In Claude, open Settings → Capabilities and turn on code execution (file creation).
    3. Go to Customize → Skills, tap +, then Upload a skill and pick the .zip.
    4. Start a chat and paste this:
      Open it in the Claude desktop app

    Works on Claude's free and paid plans. The skill is a plain text file you keep: read it, change it, share it.
