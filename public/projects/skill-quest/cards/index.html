How a card is scored

StatHow
PowerBlind judge's 1–5 score of the skill's answers (correct, complete, useful, clear) × 20
LiftHow often the skill's answer beat plain Claude's on the same task (tie = half)
ClarityA fixed checklist on the SKILL.md: same file, same score
SpeedPlain Claude's time ÷ the skill's time, capped at 100
Finds itWhether Claude picks it for the right requests among the other skills installed next to it
  • Tasks come from the skill's description only, never its instructions, so a skill can't be tuned to its own test.
  • Answer order is random and the judge is blind. One run per task, no re-rolls.
  • The judge method is adapted from Anthropic's skill-creator (Apache-2.0). Anthropic already scores skills; Skill Quest's job is making it fun for beginners.

Honest limits. One skill, three tasks: a reading, not a verdict. The scorer is built as a Claude Code plugin (score, battle, and five beginner quests) but isn't published yet, and the name "Skill Quest" is taken, so it needs a new name first.
