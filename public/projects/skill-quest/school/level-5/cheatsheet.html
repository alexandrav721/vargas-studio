1. Set menu or free chef?

SET MENU OR FREE CHEF (PATTERNS)
Augmented LLM = one call plus tools, search, memory
Prompt chaining = steps in a row, each uses the last
Routing = sort first, send to a specialist
Parallelization = at once, then combine or vote
Orchestrator-workers = a lead decides the subtasks at run time
Evaluator-optimizer = write, grade, revise
Agent = Claude picks the steps (costs more)

Say it: “We pick the simplest pattern that works. Agents only when steps can’t be planned.”

2. Build a standard outlet.

STANDARD OUTLET (MCP SERVER DESIGN)
Server offers tools, resources, prompts
Transport = the wiring
stdio = local, the app starts it
Streamable HTTP = a web server many reach
OAuth = sign in once; the app gets a limited key
Scopes = what that key may do (keep small)
Namespacing = booking_search, crm_search

Say it: “An MCP server is a standard outlet: few clear tools, the right wiring, small scopes.”

3. The kitchen system.

THE KITCHEN SYSTEM (AGENT HARNESS)
Harness = loop, tools, permissions, logs around the model
Agent SDK = Claude Code’s harness in your app
Managed Agents = Anthropic hosts it (beta)
Session = one run, in its own sandbox
Sandbox = walled-off computer where tools run
Permission policy = runs alone, or waits for a yes
Session budget = spend cap; it pauses at the cap

Say it: “The model decides. The harness runs tools in a sandbox, asks first and caps spend.”

4. A brigade of chefs.

A BRIGADE OF CHEFS (MULTI-AGENT)
Multi-agent system = a lead plus helper agents
Lead agent = plans, hands out, checks, combines
Delegation = the handoff, with a clear brief
Context isolation = each helper has its own counter
Synthesis = combining reports into one answer
Cost multiplier = agents ~4x a chat, multi-agent ~15x
Good for independent pieces; weak for tightly linked steps

Say it: “A brigade pays off only when the work splits into pieces the lead can check.”

5. Double shifts.

DOUBLE SHIFTS (CONTEXT ENGINEERING)
Context engineering = smallest set of useful tokens
Context rot = recall slips as context grows
Compaction = summarize the old shift
Context editing = clear old tool results
Memory tool = notes in a folder your app stores
Structured notes = progress log + checklist + git
Tool search = load tools only when needed

Say it: “We clear old results, compact near the limit, and leave notes for the next shift.”

6. Locks and keys.

LOCKS AND KEYS (AGENT SECURITY)
Least privilege = only the keys the job needs
Untrusted content = anything Claude reads can carry orders
Lethal trifecta = data + untrusted content + a way out; cut one
Network allowlist = only listed hosts
Vault = secrets the sandbox never sees
Approval gate = a person says yes first
Prompts steer; settings lock

Say it: “Fewest keys, everything it reads is untrusted, and a gate on what can’t be undone.”

7. Head-office checks.

HEAD-OFFICE CHECKS (GOVERNANCE)
Observability = you can see what happened
Trace = the step-by-step record of one run
Audit log = who did what, when
Human oversight = someone reviews, and can switch it off
RSP = Anthropic’s voluntary safety rulebook
AI Safety Levels = Anthropic’s safeguard sets (ASL-3 safeguards since May 2025)

Say it: “We trace every run, log who did what, and someone can switch it off.”

8. Draw the floor plan.

DRAW THE FLOOR PLAN (DESIGN DOC)
Design doc = the plan you defend; job and test first
Trade-off = what you gave up, written down
Cost model = tokens per task × price × volume
Failure mode = one way it goes wrong
Blast radius = how far damage spreads
Approval matrix = who approves which action

Say it: “Here’s the plan: the job, its test, the cost math, what can fail, and who approves.”
