# Vargas Studio

Shareable portfolio of **Alexandra Vargas**’s Cursor-built business ideas.

Friends get one link. Alexandra keeps a clear map of what’s hot vs quieter.

## Edit content

All friend-facing copy lives in [`content/portfolio.json`](content/portfolio.json).

- Rename the brand: `site.brand`
- Add/update a project: `projects[]`
- Cross-project ads/waitlists/landings: `lenses[]`
- Skills & agents: `general`

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5177

## Build

```bash
npm run build
npm run preview
```

## Note

Working title **Vargas Studio** is intentional placeholder branding until Alexandra picks a final name.
